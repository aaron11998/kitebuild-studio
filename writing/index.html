Blog explainer

Five office tasks a small business should automate first

Many small businesses lose time to copy-and-paste work. Here's where a simple script can help first.

  1. Invoice reminders. A script reads your unpaid invoices from a spreadsheet and emails a polite reminder on day 7 and day 14.
  2. Booking confirmations. Each new booking gets a confirmation message and a reminder the day before.
  3. Daily sales summary. Totals from your POS export land in your inbox at 9pm. You don't have to open a spreadsheet.
  4. Lead capture. Website form entries go straight into one sheet, tagged by source, so none get lost in email.
  5. Stock alerts. When an item drops below your reorder level, you get a WhatsApp or email alert.

Each of these is a small, scheduled script. Start with the one that annoys you most.

README sample

kite-desk

An AI receptionist for small businesses on WhatsApp. It answers common questions and offers a human handoff. Booking flows are in progress.

Quick start

git clone https://github.com/aaron11998/kite-desk
cd kite-desk && cp .env.example .env   # add GEMINI_API_KEY and WhatsApp settings
npm install && npm start

How it works

  1. WhatsApp sends each incoming message to /webhook.
  2. The server passes the message and the business's config file to Gemini, which drafts the reply.
  3. If the model is unsure, or the customer asks for a person, it offers a human handoff.
  4. Booking handling and handoff routing are still on the to-do list.

Configuration

VariablePurpose
GEMINI_API_KEYServer-side only. Never commit it.
GEMINI_MODELModel name (default gemini-1.5-flash)
BUSINESS_CONFIGA JSON file with hours, prices and FAQs (default config/demo-salon.json)
WHATSAPP_*Verify token, access token and phone number ID for the WhatsApp Cloud API

Status

Early development. It isn't connected to a live WhatsApp number yet.
